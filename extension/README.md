# Браузерное расширение TeamVault

Официальное легковесное расширение для автоматического поиска и подстановки корпоративных паролей, логинов и кодов двухфакторной аутентификации (TOTP) из TeamVault.

---

## Возможности

* ⚡ **Автозаполнение в 1 клик:** мгновенно находит сохранённый доступ по домену активной вкладки и подставляет логин и пароль в форму входа на странице.
* ⏱ **Генератор TOTP (2FA):** показывает актуальный 6-значный одноразовый код с обратным отсчетом таймера и копирует его в буфер обмена.
* 🔍 **Глобальный поиск:** быстрый поиск по всем вашим доступным хранилищам прямо из всплывающего окна расширения.
* 📋 **Безопасное копирование:** возможность отдельно скопировать логин или пароль.
* 🛡 **Сквозной аудит:** все запросы на получение паролей и кодов через расширение фиксируются в общем корпоративном журнале действий (`extension.item_filled`, `extension.totp_issued`).

---

## Установка в режиме разработчика (Developer Mode)

### В Google Chrome / Яндекс.Браузере / Microsoft Edge / Brave:

1. Откройте страницу управления расширениями в браузере:
   * **Chrome / Brave:** перейдите по адресу `chrome://extensions/`
   * **Яндекс.Браузер:** перейдите по адресу `browser://extensions/`
   * **Microsoft Edge:** перейдите по адресу `edge://extensions/`
2. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
3. Нажмите появившуюся кнопку **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку `extension` из этого репозитория:
   ```
   e:\Antigravity\team-vault\team-vault-src\extension
   ```
5. Расширение появится в списке установленных. Нажмите на значок «пазла» в панели браузера и закрепите иконку **TeamVault**.

## Настройка подключения

1. Нажмите на значок **TeamVault** в панели браузера.
2. По умолчанию расширение настроено на сервер:
   ```
   https://teamvault-demo.itsg.kz
   ```
   *(При необходимости сменить адрес нажмите на иконку ⚙ Настройки в верхнем правом углу).*
3. Введите логин и пароль вашей учётной записи в TeamVault.
4. Откройте любой рабочий сервис (например, `1cfresh.kz`, портал компании или CRM) — расширение автоматически предложит подходящие доступы.
