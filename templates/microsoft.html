Успешность входа проверяется отдельно: требуется действующий секрет и разрешение пользователя в Entra.

Что подготовить в Entra

  1. Приложение типа Single tenant.
  2. Application Client ID и Directory Tenant ID из Overview.
  3. Client Secret: скопируйте Value, а не Secret ID.
  4. Redirect URI, показанный выше.
  5. Разрешённых сотрудников в Enterprise application.

Базовый вход использует openid, profile и email. Graph-доступ к каталогу для него не требуется.
